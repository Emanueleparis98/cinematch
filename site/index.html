Il principio su cui è costruito CineMatch

Prima di installare

Domande rapide

Serve un account o una chiave API?

Serve una chiave API TMDB gratuita. Al primo avvio CineMatch apre le Impostazioni e ti guida: crei un account TMDB, copi la chiave e la incolli. La chiave resta sul tuo PC.

L'installer richiede i permessi di amministratore?

No. È un installer Inno Setup per-utente: installa in %LocalAppData%\\Programs\\CineMatch e non richiede UAC. La disinstallazione è in Impostazioni → App.

Gli aggiornamenti cancellano la mia configurazione?

No. Il setup sostituisce solo i file dell'applicazione. Configurazione, chiavi API, poster in cache e voti IMDb restano in %APPDATA%\\CineMatch.

L'app è firmata digitalmente?

La pipeline è pronta per firmare Authenticode l'eseguibile e il setup quando è disponibile un certificato. Fino ad allora Windows può mostrare l'avviso “editore sconosciuto”: puoi verificare il download dal repository GitHub ufficiale.

Perché l'anteprima dice “senza UAC” e poi Windows chiede conferma?

Windows SmartScreen può chiedere conferma per un installer non ancora firmato. Non è un prompt di amministratore: l'installazione resta nel tuo profilo.

Funziona offline?

La ricerca dei film passa da TMDB, quindi serve la connessione. L'interpretazione a regole è offline; i quattro spunti della home si generano in locale. Con Ollama puoi tenere anche l'AI sul tuo PC.
